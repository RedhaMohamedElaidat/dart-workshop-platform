🎯 Dart Workshop Activities

Activity 1: Student Average

Activity #1

Objective: Write a Dart console program that:

  • Reads the number of students
  • Reads marks for each student
  • Calculates and displays the average

Example Output: "The average mark is: 85.5"

Activity 2: Student Class with Map

Activity #2

Objective: Create a Dart program that:

  • Defines a Student class with properties: name, id, grade
  • Uses a Map to store multiple students
  • Displays student information formatted
  • Implements a method to check if student passed (grade ≥ 10)

Example Output: "Student: Ahmed (ID: 001, Grade: 15) - Passed"

Activity 3: Print Even Numbers

Activity #3

Objective: Write a Dart program that:

  • Reads a number n
  • Prints all even numbers from 1 to n
  • Constraint: Without using the modulo operator (%)
  • Use alternative methods (division, multiplication, or bitwise operations)

Example Output for n=10: "2 4 6 8 10"
